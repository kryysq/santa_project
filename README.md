# Secret Santa Web Application

Веб-застосунок на Django, який перевіряє, чи сьогодні Різдво, та дозволяє організувати гру "Таємний Санта".

## Функціонал

1. **Головна сторінка** - показує, чи сьогодні Різдво (Yes/No)
2. **Гра "Таємний Санта"** - додавання учасників, перегляд списку, рандомайзер для розподілу подарунків

## Вимоги

- Python 3.8+
- Django 4.2+

## Встановлення та запуск

1. Створіть віртуальне оточення:
```bash
python -m venv venv
```

2. Активуйте віртуальне оточення:
```bash
# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate
```

3. Встановіть залежності:
```bash
pip install -r requirements.txt
```

4. Застосуйте міграції:
```bash
python manage.py migrate
```

5. Запустіть сервер розробки:
```bash
python manage.py runserver
```

6. Відкрийте браузер та перейдіть за адресою: `http://127.0.0.1:8000/`

## Структура проєкту

- `secret_santa_project/` - основні налаштування Django
- `santa_app/` - основний додаток з логікою
  - `views.py` - обробка запитів
  - `forms.py` - форми для додавання учасників
  - `templates/` - HTML шаблони

## Алгоритм розподілу подарунків

1. Перевірка валідації (мінімум 2 учасники)
2. Випадкове перемішування списку учасників
3. Кожен учасник дарує наступному у списку
4. Останній дарує першому (замкнений цикл)

Це гарантує:
- Ніхто не дарує сам собі
- Кожен дарує рівно один подарунок
- Кожен отримує рівно один подарунок
